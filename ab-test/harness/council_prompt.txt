This is a big, important project for me, so take it seriously: build the order-details parser for Dallal, my Instagram DM sales assistant for Iraqi shops (cash on delivery). Customers send their details in DMs in all kinds of ways — Iraqi Arabic, English, mixed — and we need a clean order record: customer name, phone number, governorate, and the rest of the address (area/landmark). Bad data means failed deliveries and lost money. Make it a Python package called `dallal_parser` with a function `parse_order(text: str) -> dict` returning keys `name`, `phone` (international format like +9647XXXXXXXXX), `governorate` (English name of one of Iraq's governorates), `address`, plus whatever else you think is needed. Include tests. I won't be around to answer questions, so make reasonable decisions and document them. Put everything in ./output.
