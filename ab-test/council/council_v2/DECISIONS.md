# Decisions — Build the order-details parser for Dallal, an Instagram DM sales assistant for Iraqi shops (cash on delivery): Python package dallal_parser with parse_order(text) -> dict with name, phone (+9647XXXXXXXXX), governorate (English name), address, plus whatever else is needed. Inputs in Iraqi Arabic, English, mixed. Include tests, document decisions. Put everything in ./output.

Council: Skeptic (red team), User advocate, Domain expert — Iraqi COD delivery addresses / governorates / phone numbering / Iraqi-Arabic dialect, Quality engineer, Builder (pragmatist) · stakes standard · plan v2

- **D1** Package layout (stdlib only, Python ≥ 3.9) — `output/dallal_parser/{__init__.py, normalize.py, phones.py, gazetteer.py (data only), places.py, segment.py, followup.py, core.py, evalcases.py (shared matcher)}`, `output/eval_cases.py` CLI, `output/tests/` (unittest), `output/README.md`. Gazetteer, label and stop-word lists are plain data so the shop can extend them.
- **D2** Normalisation for matching only, output from original — Fold for matching: Arabic-Indic ٠-٩ / Persian ۰-۹ → ASCII; أإآٱ→ا, ة→ه, ھ/ہ→ه, ى→ي, ؤ→و, ئ→ي, گ→ك, ک→ك, ی→ي, چ→ج, پ→ب, ڤ→ف, Kurdish ە→ه ێ→ي ۆ→و ڵ→ل ڕ→ر; Latin casefolded. Ignorable chars (tashkeel U+064B–U+065F, U+0670, tatweel U+0640, U+200B–U+200F, U+202A–U+202E, U+2066–U+2069, U+FEFF, U+FE0F) are DROPPED from the matching copy and an index map (match offset → original offset) is kept, so `بـغـداد`, `البَصْرة` and `0770 ‏123 4567` match (O11, O14). Emoji / symbol chars (Unicode So/Sk/Cs) are treated as separators (word boundaries), never as letters (O27). Latin place matching strips a leading `al-`/`al `/`el-` and tolerates doubled letters (karrada=karada, mansour=mansoor) (O27). Arabic gazetteer lookup tolerates optional ال and one attached prefix (و، ب، ل، لل، بال، وال، وب، ول) — except for collision aliases (D4). name/address returned exactly as typed (labels, edge punctuation and edge emoji trimmed, whitespace squeezed).
- **D3** Strict phone grammar, no repair — Linear tokeniser (no backtracking regex) over the matching copy finds digit groups; groups join only across a single space/dash/dot/parenthesis/slash on the same line, optional leading `+`/`00`. Segmentation only at group boundaries. Accepted (after stripping separators): `07[3-9]\d{8}`, `7[3-9]\d{8}`, `9647[3-9]\d{8}`, `96407[3-9]\d{8}` (redundant trunk 0 → accepted + `phone_trunk_zero_removed`), with optional `+`/`00` before 964. A candidate must be bounded by non-digits — `077012345678` rejected whole (`phone_invalid_length`), never trimmed. `+`/`00` followed by a non-964 code → `phone_foreign` (covers `+44 7700 900123`, `+46 70…`, `+1 415…`). 070/071/072 → `phone_invalid_prefix`. A bare-10 obtained only by dropping a leading 1–3 digit group of the same run (e.g. `44 7700 900123`, `دار 7 7712345678`) is kept but flagged `phone_ambiguous_prefix` (blocking) (O22, partially: the NANP 3-3-4 grouping clause is rejected because Iraqis commonly write `770 123 4567`). An 07… candidate preceded by a short group (`قطاع 10 07711112222`, `دار 7 07712345678`) is accepted cleanly — the short group stays in the address. Phone-like runs of 9–15 digits that fail → warning; shorter numbers ignored. First valid = phone, second distinct = alt_phone, identical deduped, >2 → `extra_phones`. Two valid numbers separated by one space are split at the group boundary.
- **D4** Tiered gazetteer — Tier 1: the 19 governorate names (Arabic with/without ال, ه/ة, explicit spellings folding cannot produce: كربلا، كربله، دياله، حلبجه، اربل؛ English/translit: Basrah, Ninawa/Ninewa, Hawler/Hewler/Arbil, Slemani/Sulaimani/Suli, Dohuk/Dahuk/Dihok, Babil/Babel, Kerbala, Thi Qar/Dhiqar, Salahaddin/Salah al-Din, Helebce; Kurdish script هەولێر، سلێمانی، دهۆک، کەرکووک، هەڵەبجە). Tier 2: governorate capitals and districts → governorate (الموصل/Mosul/Mosel، تلعفر، سنجار؛ الحلة/Hilla/Hillah، المحاويل، المسيب؛ الكوت/Kut؛ العمارة/Amarah/Amara؛ الناصرية/Nasiriyah/Nasiriya/Nasriya، الشطرة، سوق الشيوخ؛ السماوة/Samawah/Samawa، الرميثة؛ الديوانية/Diwaniyah/Diwaniya (moved from tier 1, O23)، الشامية، عفك؛ الرمادي/Ramadi، الفلوجة/Fallujah، هيت (Arabic only)، حديثة؛ تكريت/Tikrit، سامراء/سامرا، بيجي، الشرقاط، طوزخورماتو؛ بعقوبة/Baqubah، المقدادية، خانقين؛ الكوفة/Kufa؛ الزبير، ابو الخصيب، القرنة، الفاو؛ زاخو/Zakho/Zaxo، العمادية، سميل؛ عنكاوا/عين كاوة/Ankawa، سوران، شقلاوة؛ رانية، كلار، جمجمال؛ الحويجة، داقوق؛ الهندية/طويريج، عين التمر؛ الصويرة، العزيزية؛ علي الغربي، المجر الكبير، قلعة صالح). Tier 3: unambiguous well-known neighbourhoods only (Baghdad: الكرادة، المنصور، زيونة، مدينة الصدر، مدينة الثورة، الشعلة، الدورة، البياع، الاعظمية، الكاظمية، الغزالية، حي الجهاد، السيدية، بغداد الجديدة، الزعفرانية، الجادرية، الحبيبية، شارع فلسطين، الكمالية، ابو غريب، المحمودية، التاجي، Karrada, Mansour, Zayouna, Sadr City, Adhamiya, Kadhimiya, Dora, Jadriya; Basra: العشار؛ Erbil: Dream City). Removed from tier 3 / never inference keys (O2, O10, O21): الحسينية، العامرية، اليرموك، الثورة (bare)، الشعب، الامين، البلديات، حي اور، plus generic حي الحسين، حي العسكري، الجمهورية، حي الشرطة، حي الشهداء، المعلمين، الزهراء، الاندلس، الجزائر، القادسية-as-district. Collision aliases (O4, O8) — match only with ال (no bare form, no optional-ال), never inside an order/product segment or a name span, and only as place evidence when on an address-bearing segment or after a ب/ل/من/في prefix or address label: الرمادي (grey), الكوت (coat), الهندية (Indian), حديثة (new), الشامية, المنصور, الزبير, البياع, رانية (female name; requires an address context), الامين. Matching on whole tokens, longest first. English "Hit" excluded.
- **D5** Governorate resolution and false friends — Evidence collection excludes name-labelled spans and order/product segments (اريد، ابي، اطلب، قياس، لون، اللون، سعر، حجم، قطعة، order, size, color, price — unless the segment carries an address/governorate label) (O4, O13). A hit is demoted to *landmark evidence* when (a) directly preceded by a landmark/street noun — شارع، طريق، باب، سيطرة، كراج، جامعة، جامع، مسجد، مستشفى، مول، فندق، ساحة، مجمع، حي، مطعم، مدرسة، صيدلية، محل، معرض، مكتبة، شركة، مصرف، بنك، جسر، نادي، كلية، ملعب، فرن، مخبز، عيادة، مطار، محطة، علوة، سوق، قاعة، مركز، دائرة، مديرية، بناية، street, st, road, hay, university, hospital, mall, hotel, square, restaurant, school, pharmacy, shop, market, bridge, bank, times (O5, O17); or (b) it lies inside a landmark phrase (after قرب/يم/گرب/جنب/مقابل/خلف/near/opposite/behind up to segment end) while a non-landmark place hit exists elsewhere. The حي-suppressor applies to tier-1/2 hits only; tier-3 multi-word keys (حي الجهاد، مدينة الصدر) are matched first and are not suppressed (O1). (c) Nisba/surname forms (البصري، الموصلي، النجفي، الحلي، الكربلائي، البغدادي…) are not aliases. (d) Bare عمارة = building; العمارة followed by a number/رقم/شقة/طابق, or preceded by قرب/جنب/يم/مجمع in a segment that already has a place, = building (O6). (e) Person-name governorates ميسان، مثنى، صلاح الدين (and Latin) in the leading name position (first 1–3 letter tokens before the phone or at message start, unlabelled) are name tokens when another governorate's evidence exists (O18); `القادسية`/`بابل` after a place of another governorate in the same segment are districts. Resolution: governorate capitals (tier 2 capitals) count as tier-1-equivalent for conflict checks (O7). Non-landmark hits beat landmark hits; then higher tier wins; tier 2/3 only → `governorate_inferred_from_city` (non-blocking). If surviving non-landmark hits point to different governorates: two tier-1-equivalent governorates → `multiple_governorates` (blocking) and governorate = the one attached to a delivery cue (ابعثوه/ابعثولي/ارسلوه/وصلوه/دزوه/التوصيل + ل/على/الى; send/deliver/ship to) if exactly one is, else None (O18 accepted: no first-mention guessing); a tier-1-equivalent vs a lower-tier hit of another governorate → keep the higher tier + `governorate_conflict` (blocking) (O17). Landmark-only evidence never resolves a governorate on its own. Never infer from the phone prefix.
- **D6** Labels and segmentation — Labels (Arabic dialect + English + Arabizi), optionally with one attached و (واسمي) and optionally glued to digits (رقمي07801112233) (O19): name (الاسم الثلاثي، الاسم الكامل، الاسم، اسم الزبون، اسمي، اسم، name, full name, my name is, esmi/ismi); name-intro انا/اني/ana/ani only when the next 1–4 tokens are letter-only and contain no stopword (من، ساكن/ساكنة، ب/بال-prefixed place, order verbs, greetings, gazetteer tokens) (O15, O25); phone (رقم الهاتف، الرقم الثاني، الرقم، رقمي، رقم، الهاتف، هاتف، موبايل، تلفون، واتساب، phone, mobile, number, num, tel, raqmi) — mid-line, and always for رقم/num/no/number/tel, only when followed (after optional :-=) by a digit run of ≥ 9 digits, otherwise it is address text (`زقاق رقم 5`, `street no 5`) (O3, O19, O25); `no`/`no.` only in that digit condition; governorate (المحافظة، محافظة، governorate, province; المدينة/city only at line start or before `:`); address (العنوان، عنواني، المنطقة، المحلة، اقرب نقطة دالة، نقطة دالة، اقرب نقطة، ساكن/ساكنة، address, area, landmark, location). A label ends the previous field. Segments = lines, then split on `،` `,` `/` `|` ` - `, and `.` only when followed by whitespace/end and not between digits or after st/rd (O3). Phone spans are removed before segmentation.
- **D7** Name — Priority: (1) labelled value (cut at the next label, digit run, place token, landmark word or stopword; max 5 tokens; greeting/product stoplist applied) > (2) `اسمي/my name is/انا X` phrase (same stoplist) > (3) an unlabelled segment of 1–4 word tokens with no landmark/street word (قرب، يم، گرب، جنب، مقابل، خلف، شارع، حي، قطاع، محلة، زقاق، دار، near, street, st, mall, hay, opposite), no greeting/thanks (السلام عليكم، مرحبا، هلو، شلونكم، شكرا، hi, hello, thanks), no order/product word, no question mark, and no gazetteer hit other than collision aliases/person-name governorates (منصور، امين، زبير، رانية، صلاح الدين، ميسان، مثنى) — such a segment stays a candidate when on its own line or next to the phone (O8); (4) on a single unlabelled line, in order: the letter run immediately before the phone; else the leading letter run up to the first place/landmark token (O20); else the run after the phone. Runs stop at من، و (separate token)، في، ساكن، digits, punctuation, place or landmark tokens. Word token = letters; Arabizi tokens with ≥ 2 Latin letters and < 3 digits count as words (3li) (user D7). Emoji ignored. Kunyas (ابو X / ام X) are names. Name kept as written. Once chosen, the name span is excluded from governorate evidence. Nothing qualifies → None.
- **D8** Address — Address-bearing segments (labelled address/area/landmark/governorate values, plus unlabelled segments with a gazetteer hit or a landmark/street cue) in original order, minus labels, phones, the name span, and only the span of the governorate mention that won resolution (O8/skeptic D8); suppressed/landmark hits (شارع بغداد، كراج النجف، جامعة صلاح الدين) stay verbatim; tier-2/3 places and landmark phrases kept verbatim incl. numbers (قطاع ٤٤، زقاق رقم 5، شارع 60). Greeting/product segments dropped. If what remains is empty or only the resolved governorate's capital (or its transliteration) → address None (missing, needs_review) (O9, O24). District towns (الزبير، الشطرة، زاخو…) count as an address. Address never contains a phone number or a leading label.
- **D9** Output schema and flags — Keys always present: `name, phone, governorate, address, alt_phone, needs_review, missing, warnings, followup_ar`. `missing` = core fields that are None, order name/phone/governorate/address. `needs_review` = bool(missing) OR any blocking warning (`phone_invalid_length`, `phone_invalid_prefix`, `phone_foreign`, `phone_ambiguous_prefix`, `multiple_governorates`, `governorate_conflict`, `internal_error`). Non-blocking: `governorate_inferred_from_city`, `phone_trunk_zero_removed`, `extra_phones`, `input_truncated`. Missing name alone sets needs_review. `followup_ar` comes from a closed template table (followup.py) joined in order phone, governorate, address, name with opener `هلا بيك 🌹` and closer `وشكراً`: phone missing → `ممكن رقم موبايلك؟`; phone_invalid_*/ambiguous → `الرقم ناقص أو غلط، ممكن ترسله مرة ثانية (11 رقم يبدي بـ 07)؟`; phone_foreign → `نحتاج رقم عراقي يبدي بـ 07 حتى المندوب يتصل بيك`; governorate missing → `بيا محافظة حضرتك؟`; multiple_governorates/conflict → `نوصل الطلب لـ <A> لو <B>؟` (Arabic names); address missing → `ممكن العنوان بالتفصيل: المنطقة وأقرب نقطة دالة؟`; name missing → `ممكن الاسم الكامل؟`. Invariant: followup_ar is None ⇔ needs_review is False (O16, O26). No notes/product extraction.
- **D10** Robustness — never raises: non-str coerced (`None` → ""), body in try/except → empty schema + `internal_error` (+ its followup). Input > 20,000 chars truncated (`input_truncated`). No nested quantifiers over separators; 10 KB < 200 ms; typical < 50 ms.
- **D11** Tests and eval — tests: test_acceptance.py (AT1–AT9 + merged ATs), test_phone.py, test_governorate.py, test_name_address.py, test_followup.py, test_robustness.py (seeded fuzz 2,000 strings: never raises, schema/types, phone regex `^\+9647[3-9]\d{8}$` or None, governorate ∈ 19 names or None, missing/needs_review/followup invariants; timing), test_eval_cli.py, test_cases.py (dev cases through the shared matcher; any knowingly failing case is in a KNOWN_FAILURES set with a reason, mirrored in README). Eval CLI (O12): `python3 eval_cases.py CASES.json` — if any case lacks `expected` (or `--raw`), print ONLY a JSON list `[{"id": …, "output": parse_order(input)}]` to stdout (diagnostics to stderr); otherwise per-case diffs + summary, exit 1 on failure. Matcher: NFKC, casefold, collapse whitespace, trim; `~` = contains; null matches None. Include the debaters' concrete regression inputs (grey/coat product lines, مطعم الموصل, العمارة 12 شقة 4, منصور كاظم, انا بالحلة بس ابعثوه للناصرية, فاطمة … الناصرية → address None, بـغـداد, اني من البصرة … → name None, 3li …, سارة 🌹, Mansour street no 5 …, زقاق رقم 5, 44 7700 900123).
- **D12** Documentation — README: quick start, output schema, warning table (meaning, blocking?, what to tell the customer — generated from the followup table), "Integrating in Dallal" (show followup_ar when needs_review, else send to courier), Decisions & assumptions (phone grammar, trunk zero, foreign/ambiguous prefix, 070–072, Halabja, canonical names, tiers, collision aliases, excluded generic districts, multiple-governorate rule, needs_review rule, name heuristics, output-as-typed, capital-only address → None), known limitations, how to extend the gazetteer.

## How objections were handled
- O1 [major] (Builder (pragmatist)) The 'حي' suppressor in D5(a) cancels tier-3 inference keys that D4 itself defines, so common Baghdad inputs written as 'حي X' get no governorate. → D5: حي-suppressor only for tier 1/2; tier-3 multi-word keys matched first
- O2 [minor] (Builder (pragmatist)) Tier 3 includes generic or non-unique keys, against the plan's own exclusion principle, and there is no rule for a tier-2 vs tier-3 conflict. → D4: generic tier-3 keys removed; D5 cross-tier disagreement -> governorate_conflict
- O3 [minor] (Builder (pragmatist)) Treating bare 'no' as a phone label and splitting on every '.' will cut names and addresses in English messages. → D6: no/num labels only before 9+ digit run; '.' split only before whitespace, not after st/rd
- O4 [major] (Domain expert — Iraqi COD delivery addresses / governorates / phone numbering / Iraqi-Arabic dialect) Clothing-shop words that are also tier-2 city aliases will pick the wrong governorate, either silently or with a needs_review flag on ordinary orders. الرمادي = grey (Ramadi/Anbar), الكوت = coat (Kut/Wasit), الهندية = Indian (Hindiya/Karbala). Colours and garments appear in a large share of Instagram clothing DMs. → D4 collision aliases + D5 product segments excluded from evidence
- O5 [major] (Domain expert — Iraqi COD delivery addresses / governorates / phone numbering / Iraqi-Arabic dialect) Landmarks named after cities ('مطعم الموصل', 'مدرسة البصرة', 'صيدلية بغداد', 'جسر ...') are not suppressed, because the landmark-noun list in D5(a) leaves out the most common landmark nouns. → D5(a) extended landmark nouns + landmark-phrase demotion
- O6 [major] (Domain expert — Iraqi COD delivery addresses / governorates / phone numbering / Iraqi-Arabic dialect) In Baghdad residential complexes, 'العمارة' with ال means 'the building'. D5(d) only handles bare عمارة, so building numbers become Maysan evidence. → D5(d) العمارة + number/شقة/طابق or after قرب/مجمع = building
- O7 [major] (Domain expert — Iraqi COD delivery addresses / governorates / phone numbering / Iraqi-Arabic dialect) multiple_governorates only fires between tier-1 names, but Iraqis name a governorate by its capital (الناصرية = Dhi Qar, الحلة = Babylon). Two capitals of different governorates are resolved silently by 'first mention wins'. → D5: capitals tier-1-equivalent for conflict/multiple checks
- O8 [major] (Domain expert — Iraqi COD delivery addresses / governorates / phone numbering / Iraqi-Arabic dialect) Common personal names that equal place aliases (منصور, امين, زبير via optional ال; رانية; صلاح الدين) are lost as names, and their gazetteer hit then sets or contaminates the governorate. → D4 collision aliases need ال/context; D7 such names stay candidates; name span excluded from evidence
- O9 [major] (Domain expert — Iraqi COD delivery addresses / governorates / phone numbering / Iraqi-Arabic dialect) A message with only the capital city (the usual colloquial way to name the governorate) gets an address equal to the city and needs_review False. The courier cannot deliver on that. → D8: capital-only address -> None
- O10 [minor] (Domain expert — Iraqi COD delivery addresses / governorates / phone numbering / Iraqi-Arabic dialect) Some tier-3 Baghdad keys also exist as neighbourhoods or sub-districts in other governorates, so a local customer who omits the city is routed to Baghdad. → D4: اليرموك/الحسينية/الشعب/الثورة/الامين/البلديات/حي اور removed from tier 3
- O11 [minor] (Domain expert — Iraqi COD delivery addresses / governorates / phone numbering / Iraqi-Arabic dialect) Mapping tatweel/tashkeel/ZWNJ to a space-like character breaks words apart, so stylised Instagram spellings ('بـغـداد', 'البـصرة') never match the gazetteer. ة→ه folding also cannot produce the common spellings كربله/كربلا/سامرا/دياله. → D2: ignorables dropped via index map; D4 explicit spellings كربله/كربلا/دياله/سامرا/حلبجه
- O12 [blocker] (Quality engineer) The eval CLI contract in D11 does not match the input/output format the sealed-holdout scorer requires, so the >=90% holdout gate cannot be measured. → D11: raw mode prints only JSON [{id,output}] when cases lack expected; test_eval_cli
- O13 [major] (Quality engineer) Governorate is resolved before the name span exists, so D5(c) cannot work. A name containing a governorate alias (صلاح الدين, نجف as a given name, بابل) wins first-mention and gives a wrong governorate. → Pipeline reordered: labels/segments before governorate; name-labelled spans excluded
- O14 [major] (Quality engineer) Ignorable chars (bidi/zero-width/tashkeel) mapped to a 'space-like' char will split words and break the single-separator phone join. → D2: ignorables dropped (not separators); phone joiner sees through them
- O15 [minor] (Quality engineer) The 'انا/اني/ana at start' name label captures non-names ('من', 'ساكن'). → D6: انا/اني label only before non-stopword letter tokens
- O16 [minor] (Quality engineer) followup_ar has no acceptance test or invariant. → D9: closed template table + invariant followup None <=> not needs_review; test_followup
- O17 [major] (Skeptic (red team)) The tier-1 vs tier-3 disagreement case and governorate names inside landmark phrases (restaurant/school/market) give a wrong governorate with needs_review False. → D5: landmark demotion + wider nouns; cross-tier disagreement -> governorate_conflict (blocking)
- O18 [major] (Skeptic (red team)) Common given names that are tier-1 governorate names (ميسان, مثنى, صلاح الدين) at the start of unlabelled messages produce a wrong governorate via 'first mentioned', and the name gets lost. → D5(e) person-name governorates in name position; two tier-1 without delivery cue -> None
- O19 [major] (Skeptic (red team)) Mid-line phone labels followed by a space cut addresses that contain 'رقم' (house/alley/building numbers), and labels with an attached و or no separator are missed. → D6: phone labels mid-line only before 9+ digits; attached و; glued digits
- O20 [major] (Skeptic (red team)) The single-line name fallback returns None for the common order 'name governorate area phone'. → D7(4): leading letter run up to first place token as fallback
- O21 [major] (Skeptic (red team)) Tier-3 contains generic or multi-city names that silently infer Baghdad (non-blocking per D9). → D4: removed from tier 3
- O22 [minor] (Skeptic (red team)) Foreign numbers written without '+'/'00' reach the bare-10 form after group-boundary segmentation. → D3: phone_ambiguous_prefix when bare-10 reached by dropping a 1-3 digit group; NANP clause rejected (Iraqis write 770 123 4567)
- O23 [minor] (Skeptic (red team)) Putting الديوانية in tier 1 strips the city from the address, though the city is not the same as the governorate, unlike بغداد/البصرة. → D4: Diwaniyah moved to tier 2
- O24 [major] (User advocate) A governorate capital on its own is returned as a deliverable address with needs_review False. That produces a courier-unusable record that silently passes, and it contradicts the charter's address rule and the council's own Kirkuk dev case. → D8: capital-only address -> None
- O25 [major] (User advocate) Treating انا/اني/ana at line start as a name label, combined with D7's labelled path having no stoplist, turns a very common Iraqi DM opener into the customer name. Treating 'no' as a phone label truncates English addresses. → D6/D7: انا label conditions, stoplist on phrase names, no label only before digits
- O26 [minor] (User advocate) followup_ar is accepted but has no specified content, so it may come out stiff MSA or miss the ambiguity cases (multiple_governorates, phone_foreign). Those are exactly where the shop needs a ready message. → D9: fixed template table incl. ambiguity warnings
- O27 [minor] (User advocate) English and Arabizi place forms with 'Al-' and spelling variants, and emoji next to names, are not handled. English-typing customers in districts without the governorate word will get governorate None, and emoji-decorated names will be lost. → D2: Latin al-/doubling tolerance; emoji as separators

## Chair rulings
- Chair ruling after the 1 allowed debate round: plan v2 adopts all 27 objections (amendments from every seat folded into D2-D12). Partially rejected: skeptic's O22 clause flagging bare-10 numbers written in 3-3-4 grouping as ambiguous (Iraqis commonly write '770 123 4567'; flagging would over-flag ordinary orders) - dissent recorded. Ruling on the open question of two governorates without a delivery cue: governorate None + multiple_governorates (skeptic/user position) rather than first-mentioned (builder position) - builder dissent recorded.
